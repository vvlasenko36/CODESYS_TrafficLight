# Перекресток двух светофоров

** ссылка на архив проекта: https://disk.yandex.ru/d/EEfR2gOMcza8iw

Выполнение тестового задания по созданию логики управления и визуализации двух трехсегментных светофоров, работающих на перекрестке в противофазе.

**8-фазный конечный автомат (State Machine):** Логика реализована через конструкцию `CASE`. 

Описан полноценный безопасный цикл перекрестка, исключающий одновременное включение желтых сигналов. Включены фазы подготовки (Красно-Желтый) и мигания зеленого.

Циклограмма работы перекрестка
* **Фаза 1:** С1 — Зеленый, С2 — Красный
* **Фаза 2:** С1 — Зеленый мигает, С2 — Красный
* **Фаза 3:** С1 — Желтый, С2 — Красный (Рассинхронизация)
* **Фаза 4:** С1 — Красный, С2 — Красный + Желтый (Подготовка)
* **Фаза 5:** С1 — Красный, С2 — Зеленый
* **Фаза 6:** С1 — Красный, С2 — Зеленый мигает
* **Фаза 7:** С1 — Красный, С2 — Желтый (Рассинхронизация)
* **Фаза 8:** С1 — Красный + Желтый, С2 — Красный (Подготовка)
